## Run the example project

The best way to understand SkillFoundry is to watch it work on a known-good input before pointing it at your own code.

**Run the Example Project** drops a ready-made PRD — a Todo REST API — into `genesis/todo-api.md` and runs the full pipeline:

- CRUD endpoints, SQLite migrations, validation, error handling
- Unit + integration tests
- Every quality gate, start to finish

You don't configure anything. Sane defaults are chosen for you. Just start it and watch the next step.
