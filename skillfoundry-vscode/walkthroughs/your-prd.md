## Forge your own PRD

Now do it with your own idea.

**Create a PRD** writes a new requirements document into `genesis/`. Describe what you want built — the problem, the user stories, the acceptance criteria — then run the forge pipeline the same way you just did for the example.

That's the whole workflow: **PRD → forge → gated, tested code.**

Everything deeper — autonomous mode, provider switching, memory recall, individual gate tuning — is available when you want it, in the Command Palette and the SkillFoundry settings. You never have to meet it before you're ready.
