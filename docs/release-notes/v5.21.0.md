# Release Note for v5.21.0 — Codebase Agent Wiki

The `/docs` skill can now generate and maintain a repo-wide, agent-facing wiki — documentation built for the next coding agent, grounded in real source and git evidence. Inspired by [langchain-ai/openwiki](https://github.com/langchain-ai/openwiki).

## Highlights

- **`/docs wiki` capability** — New Phase 7 of the Documentation Codifier. `/docs wiki init` builds an agent wiki under `docs/wiki/` (a `quickstart.md` entrypoint plus focused section pages); `/docs wiki update` refreshes it surgically; `/docs wiki audit` reports freshness vs git HEAD.
- **Grounding discipline** — Every claim tied to a source file, existing doc, or inspected git evidence. No invented files, APIs, or behavior. An admitted gap beats a confident guess.
- **Git-as-discovery** — Explains *why* code exists via `git log`/`blame`/`show`. Update runs inspect commits since the last successful run using a recorded `gitHead`.
- **Surgical updates** — Docs-impact plan (source change → wiki page → edit → why), soft diff budget, and a real no-op path. Run metadata in `docs/wiki/.last-update.json`.
- **Agent-actionable pages** — Each section page carries "where to start / what to watch out for / relevant tests," and top-level `AGENTS.md`/`CLAUDE.md` gets a reference section pointing to the wiki.
- **Security** — Never reads or documents `.env`/secrets; all output confined to `docs/wiki/`.
- **All 6 platforms** — Regenerated via `sync-platforms.sh` across Claude, Copilot, Cursor, Codex, Gemini, and Grok Build.

No breaking changes, no new commands or agents — a capability upgrade to the existing `/docs` skill.
