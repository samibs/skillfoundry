# Release Note for v5.19.0 — Structural Trust & Production Resilience

SkillFoundry now adapts to your project's conventions, handles production incidents without destroying governance, builds trust in the evaluator over time, and leaves an append-only paper trail of every gate decision.

## Highlights

- **Multi-user state isolation** — `.claude/local/` (gitignored) for volatile session state, `.claude/shared/` (committed) for team config. Concurrent developers no longer corrupt each other's in-flight pipeline state. Path references migrated across 6 agent files.
- **Convention discovery** — `_convention-discovery.md` reads your project before onboarding: changelog format, commit style, test file naming. Outputs `.claude/shared/conventions.json`. All agents that write commits, changelogs, or test files read this file. If the project uses `CHANGES.rst` and angular commit format — SkillFoundry respects that.
- **Hotfix pathway** — `/hotfix` for production incidents. Semgrep hard-blocks always run. Full gates (shadow tester, Anvil, evaluator, full TestLoop) are bypassed. Smoke test max 2 iterations. Mandatory follow-up story created at `genesis/hotfix-followup-*.md`. Audit trail entry written. `logs/hotfixes.md` running log.
- **Evaluator calibration** — `/evaluator --feedback "finding N was wrong — rate limiting is at the API gateway"` appends a correction to `.claude/shared/evaluator-calibration.json`. Every future evaluation loads this context before judging. `confirmed: true` marks team-verified calibrations. Commands: `--list-calibrations`, `--remove-calibration`, `--confirm-calibration`. Calibrations are context (not rules) — the evaluator still reasons with them.
- **Durable audit trail** — `_audit-export.md` writes append-only `logs/audit-trail.jsonl` after every feature commit, override decision, gate block, hotfix, and forge completion. Optional webhook via `audit_webhook` in config.json (fire-and-forget, 5s timeout, non-blocking, silent on failure). Entries queryable via grep.
- **Global profile resolution** — `~/.claude/skillfoundry-profile.json` is a personal profile that applies to every project on the machine. Team profile at `.claude/shared/team-profile.json` (committed, pulled with `/onboard --team-profile <url>`). Resolution order: global → team → project config → CLI flags.
- **Stack confidence hard block** — `_stack-profile.md` now stops execution when confidence is LOW or UNKNOWN. Shows options: confirm detected commands, override manually, or re-detect with `--verbose`. Prevents silent wrong-runner failures (running `npm test` on a Go project).
- **Security guardrail on `/quick`** — Step 2.8 scans changed files for security-critical patterns before commit: localStorage/sessionStorage tokens, hardcoded secrets, HS256, `eval()`, `exec()`. Escalates to `/feature`. Not overridable in quick mode.

## Notes

- `reports.generate_html` default changed from `false` to `true` in `.claude/config.json`.
- `/health` extended with Phase 5: shared config integrity, stale `.claude/local/` files, calibration health, audit trail validity, protocol module presence, genesis lifecycle.
- Agent count: 58 → 60 (`hotfix`, `health`).
- `.gitignore` updated: `.claude/local/` is now excluded.
- No breaking changes. Existing pipelines continue to work — the path migration is transparent to agents.
