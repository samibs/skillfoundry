# SkillFoundry v5.22.0 — Refinement Pass

**Released:** 2026-07-06

---

## What's in This Release

v5.22.0 is a **refinement release: no new features.** Every change tightens or corrects something that already existed, targeting precise modern LLMs that no longer need verbose scaffolding. Roughly **12,000 lines of repeated ceremony** were removed across all six platform trees, overlapping entry points were consolidated, and long-standing drift was corrected. No behavior was removed.

It is a 10-item prioritized pass (impact ÷ effort), plus a sync-engine fix.

## Highlights

**Prompt tightening**
- **Reflection blocks** collapsed to a single reference across 45 sources + all mirrors — the restated `## REFLECTION PROTOCOL` sections gone, each file's own self-score axes preserved (~3,000 lines).
- **Peer/Context ceremony** — two inert scaffolding blocks (`Peer Improvement Signals`, `Continuous Improvement Contract`) removed; `Context Discipline` reduced to its reference (~600 lines).
- **`go.md` version-changelog framing** — four `## NEW IN v1.x` sections re-homed under capability headers; the `NEW IN v1.3.1` section deleted as a verbatim Phase-3 duplicate; a stale dual-platform claim and a marketing block dropped.

**Entry-point consolidation**
- **`/gosm`, `/goma`, `/blitz`** collapsed to thin aliases over `/go` (each was ~400 lines of duplicated pipeline docs → 43/35/29), keeping only the one real differentiator each adds.

**Gate disambiguation**
- **Anvil agent-handoff tiers → A-namespace (A0–A6)**, ending the collision with the CLI quality gates (T0–T7) where "T3" meant "Tests" in one system and "Self-Adversarial Review" in the other. A single canonical glossary now lives in `_anvil-protocol.md`; the CLI T-system is untouched.

**Correctness & consistency**
- **VS Code forge bug** — removed a "Blitz/TDD" picker option that sent an unparsed `--blitz` flag and silently forged nothing.
- **Platform sync drift** — restored 3 skills that were missing on 4 platforms; realigned 5 drifted.
- **Sync engine** — standalone commands now generate Copilot & Cursor mirrors too (previously only Codex/Gemini), so all six platforms stay in sync from one source.
- **Stale mastheads & platform counts** — headline docs un-pinned from versions 15–19 releases behind; Penta→Hexa reconciled; `configuration.md` (which listed only 3 of 6 platforms) fixed.
- **VS Code provider picker** now shows Anthropic as the explicit default.

## Cross-Platform

Every prompt change was regenerated across all six install platforms (Claude, Copilot, Cursor, Codex, Gemini, Grok Build); sync integrity verified at 52/52 throughout.

## Upgrade Notes

- **No breaking changes, no new features.** Safe update via `git pull` / `./update.sh`.
- The `/gosm`, `/goma`, `/blitz` commands behave identically — they still dispatch to `/go` with the same flags.

See the CHANGELOG under `[5.22.0]` for the full item-by-item breakdown, and [v5.22.1](V5.22.1-RELEASE-NOTES.md) for the consistency follow-up.
