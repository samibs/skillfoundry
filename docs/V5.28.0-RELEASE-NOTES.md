# SkillFoundry v5.28.0 — Rationalization Tail: De-Theater & Gate-Keeper Unification

**Released:** 2026-07-13

---

## What's in This Release

The finishing pass on the skill rationalization that landed in v5.27.0. Two changes: a unified
gate-keeper and a framework-wide de-theater of the persona framing.

## One gate-keeper

The framework had **two** "gate keepers":

- `/gate-keeper` — quality gating + auto-fix, plus an evolved, quantified capability-gate model
  (evidence levels, thresholds, lifecycle).
- `reptilian-gate-keeper` — the *original* NASAB-Pillar-3 capability agent, whose function
  `/gate-keeper` had already absorbed ("Adapted from NASAB Pillar 3").

The reptilian one was referenced by nothing, so it was retired (**96 skills**). Its one unique
asset — a four-dimension Evidence Collection Protocol (Execution / Validation / Integration /
Reality anchors) — was grafted into `/gate-keeper`, now the single gate authority.

## De-theater

The persona framing across the whole framework was written to strong-arm weaker models into
rigor — "you are a **ruthless** senior engineer", "the **Merciless** Evaluator", "**cold-blooded**
architect", NASAB "**Reptilian** Gates", crocodile-and-apex-predator metaphors. A capable model
doesn't need theater to be exacting; it just is. And the framework's own coding-discipline module
already bans "process theater."

So the coercion language became plain, professional tone that keeps every bit of the rigor:

- "ruthless / merciless / cold-blooded" → "rigorous / exacting / unsparingly honest"
- NASAB "Reptilian Gates" → "Capability Gates"; animal capability stages (Hatchling → Apex) →
  plain (Syntax → Autonomy)
- crocodile/apex-predator aphorisms → direct statements of the same principle

**Deliberately kept:** product brand names (Forge, Anvil, Specter, ColdStart), the `cold-blooded`
*tone-config value* (renaming it would break existing `config.json` files that select it), agent
`command` ids, and the `Zero Tolerance Banned Patterns` policy. No renames, no capability change.
